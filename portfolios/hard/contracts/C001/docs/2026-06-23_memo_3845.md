# Internal memo

**To:** Gareth Moffat, Project Manager, Brackmoor Engineering Ltd
**From:** Graham Hartley, Planning Manager
**Date:** 23 June 2026
**Subject:** Monthly KPI submission for Halden Ridge Gas Compression, month end

This memo sets out the data required from each area lead for the monthly KPI submission to Norvale Energy plc. Submissions are due to me by 12:00 on the third working day after month end.

**Data required**

- Percentage complete against the baseline programme, by discipline and by Area 400 Storage
- Manhours worked, split between direct and indirect labour
- Lost time injuries, recordable injuries and near misses reported
- Requests for information raised, answered and outstanding
- Punch list items opened and closed in the month
- Inspection and test plan hold points released against those planned

**Format**

Use the template saved in the planning folder on the common data environment. Do not overwrite the previous month's file. Save the new file with the month and the area code in the title.

**Points to note**

The figures for the piping and instrumentation scope do not yet reconcile with the timesheets. Please check the labour returns for the last two weeks before you submit, as this is the main source of queries from the customer.

If any figure is an estimate rather than a measured quantity, mark it clearly so that Ruth Strachan is not misled when reviewing the pack.

Please direct any questions to me in the first instance.

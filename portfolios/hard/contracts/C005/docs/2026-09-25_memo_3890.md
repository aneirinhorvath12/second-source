# Internal memo

**To:** James Morgan, Clerk of Works, Hexley Chemicals
**From:** Ravi Kowalski, Project Manager
**Date:** 25 September 2026
**Subject:** Document control procedure update, revision 4

From the start of next week the document control procedure for Tarrow Estuary Jetty moves to revision 4. The main changes are below.

- Transmittals now carry a unique reference in the format used on the register and must be logged on the day they are issued.
- Superseded drawings are moved to the archive folder within one working day and are not left in the live issue area.
- Markups returned from site are scanned and filed against the drawing number before the marked-up print is discarded.
- Vendor documents received by email are saved to the inbox folder for Area 500 Export, not to personal drives.

Please circulate the revised procedure to your team and confirm receipt on the distribution sheet. Anyone who has been printing drawings directly from the shared drive should stop doing so until the new print log is in place.

The document controller will run a spot check of the live issue folder on Thursday. Where a superseded sheet is found in the live area, the originator will be asked to move it the same day. Questions on the revised steps can go to the document controller or to me before the site walk-round on Monday.

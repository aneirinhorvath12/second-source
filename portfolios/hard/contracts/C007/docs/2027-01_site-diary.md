### Monday 04 January 2027
**Weather:** Drizzle all day. 6°C.
**Labour:** Brackmoor 11; Orrin Commissioning 17; Ridgeway Civils 4; Tregarth Groundworks 30; total 62.
**Plant:** 3 x welding set, 3 x roller, 2 x telehandler.
**Work progressed:**
- Area 100 Inlet - Instrumentation - Install instruments
- Area 100 Inlet - Electrical - Install cable tray
- Area 300 Utilities - Structural - Install grating and handrail

- Area 200 Process - Piping - Fabricate spools (part 2 of 3)
**Notes:** Gas detection function test carried out on the Area 300 Utilities skid with the instrument technician. The panel reset was checked by the commissioning engineer before close of shift.

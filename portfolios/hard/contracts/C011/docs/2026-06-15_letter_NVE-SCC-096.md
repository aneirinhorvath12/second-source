**Description of the change**

Additional leak detection is to be provided on the storage tanks. The instruction covers the following:

- Installation of continuous leak detection on the base and lower shell of each storage tank, with the sensing arrangement to suit the tank bund layout as currently constructed.
- Connection of the new detection to the existing plant control system, with alarm and status signals to be made available in the control room.
- Testing and commissioning of the added system, including a witnessed functional test before the tanks are first filled.

Drawings and the performance requirements for the detection will be issued separately by Norvale's engineering team. Should anything in them conflict with the equipment already ordered for the tanks, please let me know promptly so that it can be resolved.

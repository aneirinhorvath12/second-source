This letter constitutes Employer's Representative's Instruction **ERI-032**, issued under clause 14 of the Contract.

**Instruction**

The Contractor is instructed to provide an additional bridge crane in the maintenance workshop at the Pellow Wind Substation, to the following outline requirements:

- Single-girder overhead travelling crane, safe working load 5 tonnes, running on its own independent crane rails and supporting columns, set parallel to and clear of the existing crane installation.
- Span and hook height to be coordinated with the workshop building and the existing crane envelope, so that both cranes can operate without interference. Pendant control, with a radio handset as an alternative.
- Power supply to be taken from the workshop distribution board, with the board's spare capacity checked as part of the design. Crane rails and columns are to be designed for the floor loadings advised in the existing slab design.

**Quotation**

In accordance with clause 14.2, please submit a quotation for this instruction within 14 days of the date of this letter. The quotation should include any effect on the programme and on the contract completion date, and set out the design, supply, installation and commissioning elements separately.
